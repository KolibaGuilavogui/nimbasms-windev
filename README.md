# Configuration des informations d'identification
Avant d'instancier un NimbaSMS, assurez-vous de disposer des informations d'identification requises. Obtenez ces informations d'identification (Basic Auth ) auprès de votre fournisseur de services SMS.

# Classe SMS pour Windev

Cette classe permet d'envoyer des SMS depuis une application Windev. Elle simplifie l'intégration avec un service SMS et fournit des méthodes pour l'envoi et la gestion des messages. Grace A NIMBA SMS

## Prérequis

* Windev
* Accès à un service SMS compatible (NIMBA SMS)
* Connexion Internet si vous utilisez un service en ligne

## Installation

1. Importez la classe dans votre projet Windev.
2. Initialisez la classe dans votre code avant de l'utiliser.
